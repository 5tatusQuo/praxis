# PRAXIS brand

The mark is "the Praxis lens": two hexagonal goggle lenses joined by a bridge.
The left lens is theory, a faint grid of cells like the ATT&CK matrix. The
right lens is practice: the same grid with one cell lit under a targeting
reticle, the rule in production. It is an original design.

| File | Use |
| --- | --- |
| `praxis-mark.svg` | Full mark with wordmark, for READMEs and slides |
| `web/app/icon.svg` | Lens-only app icon and favicon |
| `web/components/Mark.tsx` | The mark as a React component |

| Token | Hex | Use |
| --- | --- | --- |
| Obsidian | `#0E1116` | Background |
| Slate | `#1B222C` | Panels, cards |
| Brass | `#D4A24C` | Primary accent, the lit cell, calls to action |
| Signal teal | `#2EC4B6` | Covered, healthy |
| Ember | `#E5533D` | Gaps, blind rules, critical |
| Fog | `#C9D1D9` | Body text |

Type: Space Grotesk for headings and the wordmark, Inter for interface text,
JetBrains Mono for rules and queries. The heatmap unit is a hex cell, which
ties the dashboard back to the lenses.
